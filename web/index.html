              Frequently Asked Questions

              How does TunnelSats work on StartOS?

              TunnelSats manages your subscription and passes a WireGuard configuration to your Lightning node package (LND, Core Lightning or Eclair) through its clearnet-vpn action. The WireGuard interface runs inside the node container itself.

              How do I buy, renew or import a subscription?

              Use the interactive Server Region and Duration pills directly on this dashboard, or open Services → TunnelSats → Actions in StartOS:

              • Buy Subscription creates a WireGuard key on this server, fetches a Lightning invoice, and raises a Pay Invoice task on your node.
              • Renew Subscription extends the current WireGuard key in place.
              • Import Subscription installs a .conf file bought on tunnelsats.com.
              Does StartOS support automatic subscription renewal?

              Yes, via Nostr Wallet Connect (NWC). Run Services → TunnelSats → Actions → Connect Wallet and paste a nostr+walletconnect:// URI (Alby Hub, LNBits, Cashu/Minibits, or self-hosted NWC). When your subscription is within 7 days of expiry, TunnelSats requests a renewal invoice and pays it automatically (with optional Tor SOCKS5 routing).

              If your wallet budget or balance is insufficient or NWC fails 3 times, TunnelSats automatically falls back to raising a Pay Invoice task on your Lightning node and a Connect Wallet action task so you never miss a renewal. Without NWC, TunnelSats posts reminders at 7 days and 3 days before expiry.

              How do I switch between LND, Core Lightning and Eclair?

              Run Services → TunnelSats → Actions → Configure TunnelSats and select the new target node. TunnelSats asks the previous node to turn off its tunnel first and only raises the task on the new node once the previous one is off, so two nodes never share one WireGuard peer.

              What happens if the VPN drops or my subscription expires?

              When a subscription expires, the TunnelSats server disables the WireGuard peer and clearnet peer traffic stops working through TunnelSats. Renew the subscription or turn off Clearnet over VPN on the node.

              The kill switch is part of the Lightning node package. Require LND 0.21.3-beta:10, Core Lightning 26.6.8:3 or Eclair 0.14.3:3 or newer so the kill-switch rule stays armed if wg0 goes down.

              Why can I not paste my WireGuard config into this page?

              A WireGuard configuration contains your private key. StartOS service web interfaces are reachable on the local network without a login, so private keys and configuration writes are handled only inside authenticated StartOS Actions.
